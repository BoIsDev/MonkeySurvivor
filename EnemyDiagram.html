1. State Machine (EnemyBrain)

stateDiagram-v2
    direction TB
    [*] --> RUN: OnEnable
FindPlayer · Init · Subscribe

    RUN --> ATTACK: distance ≤ attackRange
    ATTACK --> RUN: distance > attackRange

    RUN --> DAMAGED: health.OnDamageTaken
    ATTACK --> DAMAGED: health.OnDamageTaken
    DAMAGED --> RUN: animation kết thúc

    RUN --> DEAD: health.OnDied
    ATTACK --> DEAD: health.OnDied
    DAMAGED --> DEAD: health.OnDied

    DEAD --> [*]: animation kết thúc
SetActive(false)
Ghi chú:
• RUN – di chuyển về phía player
• ATTACK – gọi TryAttack() mỗi frame, cooldown trong EnemyAttackBase
• DAMAGED – frozen trong animation hit react
• DEAD – chờ animation chết → trả về pool

2. Update Loop chi tiết

flowchart TD
    Start([Update mỗi frame]) --> CheckDeadDmg{state == Dead
hoặc Damaged?}
    CheckDeadDmg -->|YES| Return([return])
    CheckDeadDmg -->|NO| CalcDist[Tính distance đến player]

    CalcDist --> CheckRange{distance > attackRange?}
    CheckRange -->|YES| SetRun[SetState Run]
    CheckRange -->|NO| SetAtk[SetState Attack]

    SetRun --> MovePlayer[MoveToPlayer
nếu attack không IsExecuting]
    SetAtk --> TryAtk[attack.TryAttack player]

    TryAtk --> CheckExec{IsExecuting?}
    CheckExec -->|YES| Skip1([skip])
    CheckExec -->|NO| CheckCD{Time.time
≥ nextAttackTime?}
    CheckCD -->|NO| Skip2([skip — chờ cooldown])
    CheckCD -->|YES| Fire[OnAttackFired event
+ ExecuteAttack]

    Fire --> TriggerAnim[Brain nhận event
SetTrigger Attacking]
    Fire --> ExecImpl[Execute concrete:
Melee / Hulk / BombDrop]

5. Attack Behavior — Polymorphism

classDiagram
    class EnemyAttackBase {
        <>
        #damage: float
        #attackRate: float
        -nextAttackTime: float
        +IsExecuting: bool
        +OnAttackFired: event
        +Init(EnemyDataSO)
        +TryAttack(Transform)
        #ExecuteAttack(Transform)* abstract
        +Cancel()
    }
    class MeleeAttack {
        +ExecuteAttack(): TakeDamage trực tiếp
    }
    class HulkAttack {
        -chargeSpeed, chargeDuration, aoeRadius
        -playerLayer: LayerMask
        +ExecuteAttack(): ChargeRoutine
        +Cancel(): StopAllCoroutines
    }
    class BombDropAttack {
        -bombPrefab, riseHeight, fallDuration
        +ExecuteAttack(): BombRoutine
        +Cancel(): StopAllCoroutines
    }
    EnemyAttackBase <|-- MeleeAttack
    EnemyAttackBase <|-- HulkAttack
    EnemyAttackBase <|-- BombDropAttack

    class EnemyBrain {
        -attack: EnemyAttackBase
        +SetState(StateEnemy)
        +OnDamaged()
        +OnDead()
    }
    EnemyBrain --> EnemyAttackBase: composition
